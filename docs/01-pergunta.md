# 01 · Pergunta e objetivo

O Pix começou em 16/11/2020 e virou o meio de pagamento mais usado do país. O Banco Central publica estatísticas abertas sobre ele. Quis ver nesses números o que mudou de verdade em quase seis anos.

**Pergunta central:** como o Pix cresceu e como mudou o jeito de usar (quem paga quem, como o pagamento é iniciado, qual o valor médio)?

**Perguntas menores**
1. Quanto cresceram a quantidade e o valor das transações? O valor médio por transação mudou?
2. Existe sazonalidade (dezembro, janeiro)?
3. O Pix continua sendo "pessoa para pessoa" ou passou a ser mais usado para pagar empresas?
4. Como o pagamento é iniciado: chave, QR Code ou digitando os dados?
5. Há diferença por faixa de idade do pagador e por região?

**Habilidade que este projeto treina:** consumir uma API pública (OData), trabalhar com séries temporais mensais e dados agregados com pandas, e contar uma história com gráficos. O Olist foi SQL + Power BI; os monstros de D&D foram JSON + pandas.
